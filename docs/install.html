Install HomePlanner on a panel

Put HomePlanner on an Elecrow CrowPanel from your computer's web browser: no programs to install, no command line. It takes about two minutes.

Flicker warning: while it is being installed and when it restarts, the panel's screen may flicker, flash or go dark. If flashing lights affect you, look away or watch from the side until it shows the setup screen.

What you need

  • An Elecrow CrowPanel Advance 10.1" ESP32-P4, version 1.2 (with the ESP32-C6 Wi-Fi chip). Other panels and versions are not supported: this firmware won't work on them.
  • A computer with Google Chrome or Microsoft Edge. Safari, Firefox and phones or tablets can't install firmware (they don't have Web Serial).
  • A USB-C data cable (some cables only charge) plugged into the panel's USB-C port marked UART.
  • The driver for the panel's USB chip (a WCH CH340/CH343):
    • macOS: install WCH's CH34x driver, then allow it in System Settings → Privacy & Security and restart the Mac. The panel shows up as wchusbserial….
    • Windows: usually installed automatically. If no port appears, install WCH's CH341SER driver. The panel shows up as USB-SERIAL CH340 (COM…).
    • Linux: the driver is built in. Your user needs access to serial ports: run sudo usermod -aG dialout $USER and log out and in again. If the port disappears right after you plug in, remove the brltty package (it grabs CH340 chips by mistake).

Install

  1. Connect the panel's UART port to your computer. Close other programs that use the port (Arduino IDE, idf.py monitor, serial terminals).
  2. Click Install HomePlanner below and choose the panel's port in the list.
  3. Choose Install HomePlanner and answer the erase question (see below), then Install. Keep the cable plugged in until it says the installation is complete.

Checking for the latest version…

This browser can't install firmware. Open this page in Google Chrome or Microsoft Edge on a computer (not Safari, Firefox, or a phone or tablet). Installing only works over a secure connection. Open this page at its https:// address.

Erase the panel, or keep its settings?

The installer asks whether to erase the panel first.

  • Erase for a new panel (with Elecrow's demo), a second-hand panel, or one whose owner you don't know. This removes everything on it, including saved Wi-Fi and sign-ins.
  • Keep settings (don't erase) only when you're reinstalling your own HomePlanner panel: its Wi-Fi, Google sign-in and settings stay.
  • Already running HomePlanner? You don't need this page: tap ⚙ → Software update on the panel.

After installing

  1. The panel restarts into setup and shows a QR code with its own Wi-Fi name (HomePlanner-…) and password. (After Keep settings, it starts with your calendar instead.)
  2. On your phone, scan the QR code to join the panel's Wi-Fi hotspot, then follow Setting it up at home.

If it doesn't work

  • No port in the list: try another cable (it must carry data), the UART port, and check the driver above.
  • "Failed to connect" or the port is busy: close other programs using the port, unplug the panel for a few seconds, plug it back in and try again.
  • The panel stays dark or restarts over and over: install again and choose Erase.

The installer runs entirely in your browser (ESP Web Tools, served from this site); nothing is sent anywhere. The firmware comes from the latest HomePlanner release and is signed, so the panel only accepts updates from the same project. About HomePlanner · Privacy
